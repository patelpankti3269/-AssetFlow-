## 📌 Overview

**AssetFlow** is an Enterprise Asset Management Platform designed to help organizations efficiently manage their complete asset lifecycle.

From asset registration and allocation to maintenance, auditing, analytics, and AI-powered insights, AssetFlow provides a centralized solution for improving operational efficiency and reducing asset management complexity.

AssetFlow replaces traditional spreadsheet-based asset tracking with a modern digital ecosystem.

---

# 🎯 Problem Statement

Organizations manage thousands of assets every day:

- 💻 Laptops
- 🖥️ IT Equipment
- 🏢 Office Infrastructure
- 🚗 Vehicles
- 📦 Shared Resources

Traditional asset management methods create several challenges:

- ❌ Manual spreadsheet tracking
- ❌ Lack of real-time visibility
- ❌ Difficulty tracking ownership
- ❌ Delayed maintenance
- ❌ Poor resource utilization
- ❌ Time-consuming audits
- ❌ No intelligent decision-making

# ⚙️ Installation Guide

## Clone Repository

```bash
git clone https://github.com/patelpankti3269/-AssetFlow-.git
```

Go inside project:

```bash
cd -AssetFlow-
```

---

# Backend Setup

Navigate:

```bash
cd backend
```

Create virtual environment:

```bash
python -m venv venv
```

Activate environment:

Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run backend:

```bash
uvicorn main:app --reload
```

Backend URL:

```
http://localhost:8000
```

---

# Frontend Setup

Navigate:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start application:

```bash
npm run dev
```
